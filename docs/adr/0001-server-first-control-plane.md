# ADR-0001: независимый media service

- Статус: принято
- Дата: 2026-08-03

## Контекст

Приложение должно запускаться на сервере, с которого идёт вещание. При этом интерфейс может быть закрыт, перезапущен или открыт удалённо. FFmpeg-процесс не должен зависеть от жизненного цикла окна Electron.

## Решение

Состояние медиатеки, плейлиста и эфира принадлежит отдельному Node.js media service. React UI общается с ним через HTTP и WebSocket. Electron является необязательной оболочкой над тем же интерфейсом.

По умолчанию media service слушает только `127.0.0.1`. Удалённый доступ будет включаться явно вместе с аутентификацией и TLS или через доверенный reverse proxy.

## Последствия

Положительные:

- эфир продолжает работать без UI;
- web и desktop используют один API;
- сервис можно запускать через systemd на headless-сервере;
- проще тестировать медиаконтур отдельно.

Компромиссы:

- появляется сетевой контракт между UI и сервисом;
- нужно синхронизировать версии API;
- для удалённого управления потребуется отдельная модель безопасности.
