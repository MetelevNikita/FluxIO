# Эфирные эффекты второго уровня

Применимо к FluxIO **v7.0.12**.

Инструкция для инженера эфира: как применять шесть параметрических эффектов
вкладки `Effects` — Animation in/out, Dynamic title, Next program, Ticker crawl,
Clock / countdown и Stinger transition.

## 1. Три уровня графики

FluxIO различает три уровня эфирной графики. Уровень видно по цвету в левой
части вкладки `Effects` и по цвету чипа в строке ролика.

| Уровень | Что это | Где настраивается | Цвет |
|---|---|---|---|
| 1 | Логотип канала и возрастная плашка ролика | Playlist, вторичный ряд строки | зелёный |
| 2 | Шесть параметрических эфирных эффектов этой инструкции | Effects → каталог «Эфирные эффекты» | **синий** |
| 3 | Импортированный Lottie/alpha-оверлей | Effects → `Import Lottie / media` | **жёлтый** |

Разница между уровнями 2 и 3 принципиальная:

- **Уровень 3** — это картинка. Оператор сам решает, на какой ролик её положить
  и в каком окне показать.
- **Уровень 2** — это правило. Эффект сам находит нужные ролики, сам считает
  моменты запуска и сам подставляет текст. Lottie-пресет уровня 3 служит ему
  только оформлением.

Поэтому эффект второго уровня нельзя добавить селектором `FX` в строке ролика —
в этом списке его нет. Он применяется только с вкладки `Effects`.

## 2. Общий порядок применения

1. Откройте вкладку `Effects`.
2. В синей полосе «Эфирные эффекты» нажмите нужный эффект — в библиотеке
   появится синяя карточка.
3. Выберите её. В правом инспекторе откроется блок настроек с бейджем
   `Уровень 2`.
4. Если эффекту нужна графика, выберите **Lottie-пресет** в первом поле.
   Список содержит только эффекты уровня 3, уже импортированные в проект.
   Значит, пресет надо импортировать заранее — `Import Lottie / media`.
5. Задайте настройки эффекта.
6. Нажмите `Add to entire project` либо выберите ролик и нажмите `Add to clip`.
7. Прочитайте сообщение под заголовком вкладки: там число обработанных роликов,
   первое предупреждение и первая ошибка привязки.
8. Проверьте результат в `Playlist` → раскрытая строка ролика: синие чипы `L2`
   и синие дорожки в блоке `Timeline Trimming`.

Повторное нажатие `Add to entire project` добавляет **ещё один** комплект слоёв.
Чтобы переприменить эффект с новыми настройками, сначала снимите старый —
`Trash` на карточке эффекта убирает и слои, и надписи, и звуковые вставки во
всех расписаниях.

Эффект уровня 2 применяется сразу к `Current` и `Future`. Все окна показа
считаются от **эфирной** длительности ролика (`declaredDurationSeconds`), а не
от длины файла.

## 3. Animation in/out

Пресет входной и/или выходной анимации, привязанный к конкретным роликам файлом
задания.

### Настройки

| Поле | Значение |
|---|---|
| Lottie-пресет | Обязателен. Из его текстовых полей берутся ключи. |
| Режим | `In`, `Out` или `In + Out`. |
| Start, с | Момент запуска входной анимации **от начала** ролика. |
| End, с | Момент завершения выходной анимации **от конца** ролика. `0` — точно в конце. |
| Duration, с | Длительность каждой из анимаций. |
| Файл задания .json | Необязателен. Без него все выбранные ролики получают шаблонный текст. |

Окна получаются такие:

```text
IN :  [Start,                       Start + Duration]
OUT:  [Длительность - End - Duration, Длительность - End]
```

### Файл задания

Принимаются две формы. Один объект — как в исходной спецификации:

```json
{
  "name": "Инзерские зубчатки",
  "eng": "Inzer Cogs",
  "rus": "Инзерские зубчатки",
  "region": "Республика Башкортостан"
}
```

Массив объектов — одно задание на всю недельную сетку:

```json
[
  { "name": "Инзерские зубчатки", "eng": "Inzer Cogs" },
  { "name": "Вечерние новости",   "eng": "Evening News" }
]
```

### Правила сопоставления

- `name` — служебный ключ. В Lottie он не передаётся.
- Ролик ищется по полному совпадению названия. Перед сравнением снимаются
  пробелы в начале и конце строки.
- Остальные ключи сопоставляются с **именами текстовых слоёв** Lottie, а для
  Essential Graphics — с **идентификаторами слотов**. Сравнение точное и с
  учётом регистра: `eng` и `ENG` — разные ключи.
- Ключа нет в задании — поле сохраняет значение по умолчанию из шаблона.
- Ключа нет в Lottie — он игнорируется и попадает в предупреждения.
- Значение не строка — ключ игнорируется, в предупреждениях появляется строка
  `key "…" is ignored because its value is not a string`.
- Ролик не найден или найдено несколько роликов с таким названием — **ошибка
  привязки**, эффект для этой записи не применяется.
- Одно и то же `name` встречается в файле дважды — берётся последняя запись,
  в предупреждениях появляется `appears more than once`.

Ролики с одинаковыми значениями ключей склеиваются в один Lottie-рендер, поэтому
недельная сетка не создаёт сотни одинаковых файлов.

## 4. Dynamic title

Универсальная плашка для имени, статуса или любого другого значения. Lottie
рисует только анимированный декор и фон, а текст всегда остаётся отдельной
надписью FFmpeg.

| Поле | Значение |
|---|---|
| Декор и подложка Lottie | Необязательны. Без пресета FFmpeg сам рисует фон с padding. |
| Источник текста | Вручную либо JSON-файл задания. |
| Текст | Реальная строка; при файле задания — резервное значение. |
| Ключ значения | Поле записи JSON, которое надо показать. Запись ищется по `name` ролика. |
| Start / Duration, с | Окно показа внутри ролика. |
| Поле для текста | Text Layer пресета, который очищается и заменяется `drawtext`. |
| Поле / текст подписи | Необязательная постоянная подпись, запекаемая в Lottie. |

Пример файла задания:

```json
[
  { "name": "Инзерские зубчатки", "status": "Премьера" },
  { "name": "Вечерние новости", "status": "Прямой эфир" }
]
```

Для резиновой подложки оставьте в After Effects текст настоящим Text Layer, а
Shape Layer с прямоугольником назовите `fit:<имя текстового слоя>`. Перед
рендером FluxIO очистит шаблонную надпись, измерит реальное значение тем же
шрифтом и кеглем и изменит ширину прямоугольника, сохранив исходные отступы.

## 5. Next program

Плашка «Смотрите далее» с названием следующего материала.

| Поле | Значение |
|---|---|
| Пресет плашки | Необязателен. Без пресета плашка рисуется штатной надписью FFmpeg. |
| Start offset, с | За сколько секунд **до конца** ролика показать плашку. |
| Duration, с | Сколько плашка держится. |
| Источник названия | `Следующий ролик плейлиста` либо `Файл задания, ключ next_title`. |
| Поле названия | Text Layer Lottie, который очищается и заменяется живой надписью FFmpeg. |
| Поле подзаголовка | Необязательная постоянная подпись, запекаемая внутрь Lottie. |
| Резервный текст | Показывается на последнем ролике. Пусто — эффект пропускается. |

Анонсируется **следующий фильм**, а не следующая строка расписания: между
фильмами стоят отбивки и ролики, объявлять их незачем. Тип берётся из разметки
расписания (`movie` / `chop` / `clip`). Если расписание не размечено по типам
вовсе, берётся просто следующий элемент.

Название всегда берётся из **плейлиста**, а не из следующего
выделенного ролика. Если применить эффект к одному ролику в середине сетки,
подставится тот материал, который реально пойдёт за ним в эфир.

На последнем ролике расписания следующего элемента нет. Без резервного текста
эффект туда не ставится и выдаёт предупреждение — это нормально.

Название следующего материала не запекается в Lottie. FluxIO очищает выбранный
Text Layer и рисует реальную строку через `drawtext`, используя его положение,
кегль, цвет и выключку. Поэтому один пресет работает для всей сетки и любых
названий. Для резиновой подложки назовите Shape Layer
`fit:<имя поля названия>`, например `fit:next_title`: перед рендером FluxIO
измерит конкретное название следующего фильма и сохранит отступы шаблона.

## 6. Ticker crawl

Бегущая строка. Скорость постоянна и не зависит от длины текста: положение
надписи считается покадрово с учётом её реальной ширины.

| Поле | Значение |
|---|---|
| Подложка под строку | Необязательный Lottie/alpha пресет. Сам текст всегда рисует FFmpeg. |
| Источник текста | `Вручную` — поле ниже, по сообщению в строке; `Файл .json / .txt`; `RSS / Atom-лента`. |
| Скорость | Пикселей кадра в секунду. 120 — спокойная новостная строка. |
| Направление | Справа налево или слева направо. |
| Повторов | `0` — крутить непрерывно всё окно. Больше нуля — после последнего круга строка уходит за кадр. |
| Start / Duration, с | Окно показа внутри ролика. |
| Разделитель | Ставится между сообщениями и замыкает круг, чтобы последнее не склеилось с первым. |
| Оформление надписи | Кегль в % от высоты кадра, позиция в % от кадра, цвета, подложка. |

Форматы файла сообщений:

```text
messages.txt — одно сообщение в строке
```

```json
["Первое сообщение", "Второе сообщение"]
```

```json
{ "items": ["Первое сообщение", "Второе сообщение"] }
```

Берутся первые 200 сообщений. Пустые строки и нестроковые значения
отбрасываются с предупреждением.

### Новости из интернета

Выберите источник `RSS / Atom-лента`, вставьте адрес и нажмите `Загрузить`.
Ленту качает media-service, а не окно приложения. Берутся заголовки записей
(`<item>` у RSS, `<entry>` у Atom); заголовок самой ленты новостью не считается.

Новости **не обновляются сами**. Чтобы выдать в эфир свежие заголовки, нажмите
`Загрузить` ещё раз и примените эффект заново.

### Шрифт и русский язык

Строку рисует FFmpeg конкретным файлом шрифта. Шрифт по умолчанию может не
содержать кириллицы — тогда русский текст выйдет в эфир пустыми
прямоугольниками. В блоке `Оформление надписи` список системных шрифтов разделён
на две группы: **с поддержкой кириллицы** и **без**. Выбирайте из первой.

Если в тексте есть кириллица, а шрифт не выбран, при применении эффекта
появится предупреждение.

Кегль задаётся в процентах от высоты кадра, поэтому одна и та же настройка
одинаково выглядит в SD, FHD и UHD.

## 7. Clock / countdown

Экранные часы или обратный отсчёт.

| Поле | Значение |
|---|---|
| Подложка под часы | Необязательный пресет. |
| Режим | `Часы` или `Обратный отсчёт`. |
| Формат | `HH:MM:SS`, `HH:MM`, `MM:SS`, `SS`. |
| Часовой пояс | Только для часов. Минуты относительно UTC: Москва — `180`. |
| Длительность отсчёта, с | Только для отсчёта. С какого значения он начинается. |
| Start / Duration, с | Окно показа внутри ролика. |
| Поле для значения | Text Layer Lottie, который очищается и заменяется живыми часами/отсчётом. |

Часы идут по **эфирному** времени ролика, а не по системным часам машины.
Это важно: FluxIO запускает рендерер следующего ролика заранее, и обычные
системные часы показали бы в первых кадрах будущее время. Отсчёт привязан к
точке запуска окна и приходит в ноль ровно через заданное число секунд без
накопления ошибки.

Если окно показа короче длительности отсчёта, таймер исчезнет с экрана, не
дойдя до нуля. Интерфейс предупреждает об этом при применении.

Часы и отсчёт всегда рисуются через `drawtext`, потому что значение меняется
на каждом кадре. Lottie отвечает только за анимацию и фон. Для адаптивной
подложки назовите Shape Layer `fit:<имя поля для значения>`, например
`fit:clock`. При рендере используется самое широкое значение выбранного
формата (`00:00:00`, `00:00`, `00`), поэтому ширина плашки не прыгает во время
работы часов.

## 8. Stinger transition

Брендированный переход, закрывающий стык двух роликов.

### Как он устроен

Эфир FluxIO катится независимыми рендерерами — по одному процессу на ролик.
Стык двух роликов проходит ровно по границе этих процессов, поэтому один общий
оверлей поверх обоих роликов технически невозможен.

Переход режется по точке `Cut point`:

```text
              Cut point
                  │
  ролик A ────────┤────────  ролик B
  [0 … Cut point) │ [Cut point … Duration)
   на хвост A     │   на голову B
```

Кадры до `Cut point` ложатся на хвост ролика A, кадры после — на голову ролика
B из того же файла. Переключение источника остаётся штатным стыком плейлиста и
происходит ровно там, где графика полностью закрывает кадр. Длительность
расписания, PCR, SCTE-35 и сетка эфира при этом не меняются.

### Настройки

| Поле | Значение |
|---|---|
| Файл перехода | `MOV`, `WebM`, `MP4`, `M4V`. Для настоящей альфы — ProRes 4444 или VP9 с alpha. |
| Duration, с | Полная длительность перехода. |
| Cut point, с | Момент полного перекрытия кадра. Строго внутри `Duration`. |
| Режим наложения | `Alpha` — у файла есть альфа-канал. `Luma` — вырезать чёрный фон. |
| Порог яркости | Только для `Luma`: всё темнее считается фоном. |
| Подмешивать звук перехода | Звук берётся из того же файла и режется тем же швом. |
| Уровень звука, дБ | Относительно авторского уровня файла. `-6` — заметно, но не перекрывает программу. |

### Порядок применения

1. Выберите файл перехода.
2. Найдите в нём кадр полного перекрытия и запишите его время — это `Cut point`.
3. Задайте `Duration` и `Cut point`. **Обе величины округляются до границы
   кадра проекта.** При 25 fps значение `0.5` не лежит на сетке и будет
   поправлено на `0.52`; интерфейс сообщит об этом предупреждением.
4. Выберите ролик, **после которого** нужен переход, и нажмите `Add to clip`.
   `Add to entire project` ставит переход на каждый стык расписания.
5. Проверьте в `Playlist`: у ролика A появится синяя дорожка в конце, у ролика
   B — синяя дорожка `HEAD` в начале.

### Что нужно знать

- Переход ставится **после** выбранного ролика. На последнем ролике расписания
  стыка нет — эффект туда не ставится и выдаёт предупреждение.
- Если ролик короче своей половины перехода, переход подрезается, о чём
  сообщает предупреждение.
- Звук перехода подмешивается **во все языковые дорожки** одинаково: программа
  одна, и служебные звуки в дорожках обязаны совпадать.
- Файл без звуковой дорожки при включённом звуке молча пропускается на старте
  эфира — это защита: отставший аудиовход останавливает мультиплексор целиком.

## 8a. Предпросмотр

У каждого эффекта в инспекторе есть кадр предпросмотра. Бегущая строка едет с
заданной скоростью выбранным шрифтом и цветами, часы идут, отсчёт считает, у
стингера показана схема стыка с точкой Cut point.

Предпросмотр рисует приложение, а не FFmpeg. Шрифт, цвета, положение и поведение
совпадают с эфиром; сглаживание и кернинг могут отличаться. Экранные часы в
предпросмотре идут по часам этой машины, а в эфире — по эфирному времени ролика.

## 8b. Правка в плейлисте

Назначенная бегущая строка, часы и отсчёт видны в `Playlist`:

- синим чипом в строке ролика — с названием и режимом; корзина на чипе снимает
  надпись с этого ролика;
- отдельной дорожкой в `Timeline Trimming` — её можно перетащить мышью, подрезать
  краями и удалить кнопкой справа.

Правки будущих роликов уходят в эфир на лету, без остановки.

## 9. Порядок наложения в кадре

Снизу вверх:

```text
видео ролика
  └─ возрастная плашка (уровень 1)
      └─ логотип ролика (уровень 1)
          └─ FX-слои в порядке добавления (уровни 2 и 3)
              └─ динамические надписи: Dynamic title, бегущая строка, часы, отсчёт (уровень 2)
```

Динамические надписи всегда сверху — они обязаны оставаться читаемыми.

## 10. Изменения на лету и Stop/Start

| Изменение | Как применяется |
|---|---|
| Animation in/out, Dynamic title, Next program, Ticker crawl, Clock / countdown у **будущих** роликов | На лету, через `PUT /api/playout/playlist` |
| Stinger transition у **будущих** стыков | На лету |
| Любой эффект на **текущем** ролике | Только со следующего ролика |
| DVB subtitle PID, SCTE-35 cue plan | Требуют Stop/Start |

Правило то же, что и для остальной графики: параметры будущих роликов
подхватываются без разрыва эфира, параметры транспортной сессии — нет.

## 11. Требование к сборке FFmpeg

Dynamic title, бегущая строка, экранные часы и обратный отсчёт рисуются фильтром `drawtext`.
Он есть только в сборках FFmpeg с **libfreetype**. Обычная формула Homebrew
`ffmpeg` собрана без него — ровно как и без libass для burn-in субтитров.

Проверить:

```bash
ffmpeg -hide_banner -filters | grep drawtext
```

Пусто — установите полную сборку:

```bash
brew install ffmpeg-full
```

Без `drawtext` Start не запустится: preflight остановит эфир заранее и назовёт
причину. Animation in/out, Next program с пресетом и Stinger transition при этом
работают — им `drawtext` не нужен.

## 12. Ограничения v7.0.0

- Пресетом эффекта второго уровня может быть только уже импортированный эффект
  уровня 3. Импортируйте Lottie заранее.
- Содержимое файла задания держится в памяти сессии. После перезапуска
  приложения путь к файлу сохраняется, но перед повторным применением файл
  нужно перечитать кнопкой `Обновить`.
- Бегущая строка и часы используют системный шрифт по умолчанию. Отдельный
  шрифтовой файл в интерфейсе пока не выбирается.
- Обратный отсчёт не вызывает следующее событие — он только показывает время.
- Окна динамических надписей в `Timeline Trimming` показаны, но не двигаются
  мышью: их границы задаёт сам эффект на вкладке `Effects`.
