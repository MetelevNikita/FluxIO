# Этап 05-17 — пакетное применение Animation In/Out из JSON — v7.0.16

## Результат

Во вкладке Effects у эффекта Animation In/Out появился отдельный рабочий поток
для больших титровальных заданий. Оператор загружает массив JSON, связывает
поле `title` с именем ролика и произвольные ключи (`rus`, `eng`, `ital`, `fre`
и другие) с одноимёнными Text Layer шаблона, затем одной кнопкой раскладывает
титры по Current и Future.

## Формат задания

```json
[
  {
    "title": "NEWS_01",
    "rus": "Новости",
    "eng": "News",
    "ital": "Notizie",
    "fre": "Actualités"
  }
]
```

JSON Parser показывает ключи и значения первого объекта рядом с Text Layer
плашки. Он автоматически предлагает `title` как идентификатор и сопоставляет
одноимённые поля, но оператор может вручную назначить любые связи, например
`media_id → идентификатор` и `title_ru → rus`. Идентификатор в Lottie не передаётся.
Готовый пример сохранён в `docs/animation-in-out-task.example.json`.

## Логика применения

- имя сравнивается без пути, расширения, регистра и крайних пробелов;
- одна запись применяется ко всем повторам ролика в обоих расписаниях;
- отсутствующие в расписании записи JSON пропускаются и считаются в превью;
- ролики без записи остаются без выбранного Animation In/Out;
- дубли `title` в JSON блокируют применение как неоднозначные;
- повторное применение заменяет только слои этого эффекта и не копит дубли;
- другие эффекты, текстовые оверлеи и ручные FX сохраняются.

Отзывчивая подложка продолжает работать через Shape Layer
`fit:<Text Layer>`: для каждого языка FluxIO измеряет подставленный текст и
пересчитывает ширину прямоугольника до Lottie-рендера.
