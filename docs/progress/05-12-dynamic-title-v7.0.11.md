# 05.12 — Dynamic title v7.0.11

Дата завершения: 2026-08-20.

Добавлен универсальный гибридный эфирный эффект `Dynamic title`: Lottie отвечает
только за анимированный декор и подложку, а изменяемую строку рисует FFmpeg через
`drawtext`.

Реализовано:

- текст задаётся вручную или читается для каждого ролика из JSON-файла задания;
- запись файла задания сопоставляется с роликом по `name`, ключ значения выбирает оператор;
- выбранный Text Layer Lottie очищается перед рендером, поэтому шаблонный текст не остаётся под надписью;
- надпись наследует положение, кегль, цвет и выключку выбранного текстового слоя;
- Shape Layer с именем `fit:<имя текстового слоя>` пересчитывается под реальное значение;
- для каждого значения используется его собственный `fitSample`, поэтому сохраняются отступы шаблона;
- без Lottie-пресета эффект работает как обычная адаптивная плашка `drawtext`;
- добавлены настройки источника, тайминга, привязки полей, шрифта и preview.

Проверка:

- общий TypeScript typecheck;
- полный набор unit-тестов проекта;
- тест разделения Lottie-плашки и статического `drawtext`;
- тест значений из файла задания и резервного текста.
