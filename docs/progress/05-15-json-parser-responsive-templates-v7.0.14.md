# Этап 05-15 — JSON Parser и отзывчивые пользовательские шаблоны — v7.0.14

## Результат

Графический контур получил единый слой данных для всех текстовых эффектов
второго уровня. Внешний JSON больше не обязан повторять имена Text Layer:
оператор связывает поля в отдельном окне JSON Parser, а mapping сохраняется
в определении эффекта.

## Что реализовано

- разбор одного объекта или массива до 2000 записей;
- строки, числа, boolean и вложенные dotted keys;
- выбор произвольного поля для сопоставления записи с именем ролика;
- автоматическое и ручное сопоставление JSON → Text Layer;
- таблица примеров и заполненности полей;
- общий mapping для Animation in/out, Dynamic title, Next program,
  Ticker crawl и Clock / countdown;
- обнаружение Shape Layer `fit:<Text Layer>` и индикатор `FIT READY`;
- подстановка дополнительных полей в любой импортированный Lottie-пресет;
- переработанный UI «Шаблон → Данные → Эфир → Оформление»;
- демонстрационный проект для визуальной проверки в dev-режиме.

Stinger transition остаётся переходом без текстовой модели данных: он принимает
Lottie или alpha-видео, но JSON mapping для него не показывается.

## Совместимость

Старые файлы с ключом `name` продолжают работать без настройки: при пустом
mapping все остальные ключи сопоставляются с одноимёнными полями шаблона.
Старые определения эффектов получают `dataMapping` через defaults контракта.
