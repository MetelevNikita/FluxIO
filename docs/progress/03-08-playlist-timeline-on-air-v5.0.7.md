# 03.08 — календарная шкала и эфирная позиция v5.0.7

Дата завершения: 2026-08-08.

## Результат

- Current начинается в понедельник текущей недели, Future — в следующий
  понедельник; дата-якорь сохраняется в PostgreSQL snapshot.
- В Playlist добавлены sticky-разделители дня, дата и точное время старта
  каждого ролика с учётом `start on`, `delay` и планового хронометража.
- Media-server отдаёт стабильный ID ролика, позицию и процент внутри него.
- Активный ролик выделяется зелёным `ON AIR` и прогресс-линией; при смене ролика
  список автоматически прокручивается к нему.
- Аварийная точка восстановления выделяется оранжевым `STOPPED HERE` и также
  автоматически помещается в видимую область.
- Левая часть экрана расширена до 48% (не менее 560 px), preview уменьшен до
  620 px и сохраняет 16:9.
- Макет Playlist синхронизирован с Figma.

## Совместимость

Старые snapshot без `anchorDate`, `currentItemId` и позиции внутри ролика
остаются валидными: используются вычисляемая неделя и прежний индекс/общий
таймкод как fallback.

## Проверка

- web TypeScript typecheck;
- unit-тест календарной шкалы, перехода через полночь и `delay`;
- media-server tests для checkpoint и playout status;
- полный root typecheck/test после синхронизации версии.
