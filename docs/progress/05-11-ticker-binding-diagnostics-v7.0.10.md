# 5.11. Почему привязанная строка не видна (v7.0.10)

## Разбор жалобы

Оператор привязал бегущую строку к полю `Инициал Ди` и не увидел её в кадре.
Воспроизведение его настроек показало: строка **создаётся** — план даёт слой
плашки и надпись, ошибок нет. Но получившийся фильтр объясняет всё:

```text
drawtext=text='TEST TEST TEST':x='w-mod((max(0,t-0)*200),(w+tw))'
  :y='949-th/2':fontsize=66:fontcolor=#000000
```

Два обстоятельства складываются в «строки нет»:

1. **Цвет унаследован от слоя плашки — чёрный** (`fc: [0,0,0]` у `Инициал Ди`),
   и собственная подложка надписи выключена: её роль должна играть плашка.
2. **Строка едет по всей ширине кадра** (`w` = 1920), а плашка занимает 782 px.
   За её пределами чёрный текст идёт по тёмному видео и практически не виден.

Отрисовка кадра с этими параметрами подтвердила: текст присутствует, но лежит
справа от плашки на тёмном фоне.

## Что сделано

**Предупреждение при применении.** Строка привязана к полю плашки, а полоса
осталась во весь кадр — план сообщает об этом прямо, с указанием, какие поля
задать. Раньше сочетание молча давало нечитаемый результат.

**Полоса видна в предпросмотре.** Пунктирная рамка показывает, где строка будет
обрезана, а сама строка в предпросмотре ездит внутри этой полосы — подобрать
границы можно на глаз, не запуская эфир.

## Почему полоса не подбирается автоматически

Ширину плашки из Lottie взять неоткуда: у точечных текстовых слоёв нет размера
блока (`sz`), а вычисление прямоугольников подложек через цепочку родителей на
файле оператора разошлось с реальным рендером примерно на 230 px — фигуры лежат
внутри групп со своими трансформациями. Подставлять оператору заведомо неточные
границы хуже, чем показать полосу и дать её задать.

Для пресета `test sh` подходящие значения: белая подложка — `X ≈ 18`,
`ширина ≈ 41`; красная — `X ≈ 5.6`, `ширина ≈ 15.7`.

## Проверка

- `npm run typecheck` — без ошибок.
- `npm test` — 154 теста, 0 падений.
- Новый тест: полоса во весь кадр при привязке даёт предупреждение, суженная —
  не даёт и доходит до оверлея.
