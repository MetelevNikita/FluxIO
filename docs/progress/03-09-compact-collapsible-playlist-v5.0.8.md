# 03.09 — компактные раскрываемые строки Playlist v5.0.8

Дата завершения: 2026-08-08.

## Результат

- раскрытый элемент Playlist перестроен из двух строк в один горизонтальный ряд
  высотой 58 px;
- имя материала занимает гибкую колонку, использует container-relative размер
  шрифта и `ellipsis`, поэтому не накладывается на controls;
- AGE, LOGO, schedule type, start/take и delete остаются в той же строке;
- индивидуальная кнопка раскрывает и сворачивает каждый материал;
- свёрнутая строка высотой 38 px оставляет эфирное время, название, AGE и LOGO;
- `ON AIR` и `STOPPED` сохраняются в компактном представлении;
- над списком добавлены `Expand all` и `Collapse all` для активной вкладки;
- состояние Current и Future хранится раздельно по ID материалов до закрытия
  интерфейса;
- макет Playlist v5.0.8 синхронизирован с Figma рядом с предыдущей версией.

## Проверка

- web TypeScript typecheck;
- root tests;
- production build;
- визуальная проверка раскрытых и свёрнутых строк в Figma.
