# 04.03 — вторичные controls и Timeline Trimming v6.0.2

Статус: завершено 2026-08-10.

## Реализовано

- раскрытая строка ролика разделена на основной и вторичный уровни;
- `Start here` сохраняет полную подпись и закреплён справа верхнего ряда;
- нижний ряд следует операторскому порядку: `SRT`, селектор `FX`, назначенные FX-слои;
- горизонтальное переполнение FX не перекрывает эфирные controls;
- шкала времени и слои FX/SRT/VIDEO находятся в секции `Timeline Trimming` под её заголовком;
- свёрнутые строки и групповые операции Playlist сохранены без изменений;
- макет Playlist синхронизирован с Figma отдельной версией v6.0.2.

## Проверка

- TypeScript typecheck всех workspaces;
- media-server, web и cross-platform setup tests;
- production build всех npm workspaces;
- визуальная проверка нового Playlist frame в Figma.
