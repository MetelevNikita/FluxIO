# 04.18 — Повторные FX и тёмные selectors v6.0.17

Статус: завершён 2026-08-11.

## Реализовано

- `Add to clip`, `Add to entire project` и Playlist selector разрешают
  многократно назначить один и тот же эффект.
- Каждое назначение создаёт новый `GraphicEffectLayer` с уникальным `id`.
  Экземпляры независимо перемещаются по timeline, имеют собственные IN/OUT и
  удаляются отдельной корзиной.
- Повторное назначение не создаёт дубликат в Effect Library: дублируются только
  слои внутри ролика, а исходный проект эффекта остаётся один.
- Все native selectors внутри Effects получили `color-scheme: dark`, чёрный фон
  и контрастный текст. Исправлена незаданная переменная `--surface-raised`, из-за
  которой `Target clip` на Windows открывался белым с жёлтым текстом.

## Проверка

- regression test дважды назначает один effect ID одному клипу и получает два
  слоя с разными instance IDs;
- `npm run typecheck`;
- web tests;
- production build и полная регрессия монорепозитория.
