# 5.9. Один эффект — один чип, порядок эффектов перетаскиванием (v7.0.8)

## «Почему добавляется два эффекта»

Это не дубль. Эффект второго уровня кладёт на ролик до двух сущностей:

- **плашку** из Lottie-пресета — готовый отрендеренный файл, обычный FX-слой;
- **живое значение** — часы, отсчёт, бегущую строку, которые FFmpeg рисует
  покадрово и в отрендеренный файл не запекаются.

В плейлисте они показывались двумя записями, и одно применение выглядело как два
эффекта. Теперь чип один на эффект, с пометкой состава — `CLOCK+ПЛАШКА` — и
подсказкой «плашка из пресета плюс живое значение». Корзина на чипе снимает
эффект с ролика целиком: снять одну половину значило бы оставить на ролике
половину эффекта.

В блоке `Timeline Trimming` обе дорожки остаются раздельными: плашку и значение
может понадобиться подрезать по-разному.

## Порядок эффектов перетаскиванием

Карточки в левой части вкладки `Effects` перетаскиваются мышью. Линия сверху
показывает, куда встанет карточка; сброс мимо карточек переносит её в конец
списка.

## Про вставку значения в поле плашки

Реализовано в v7.0.7: у Ticker crawl и Clock / countdown есть поле
**«Поле для значения»**, и при выбранном поле значение встаёт внутрь плашки с её
кеглем, цветом и выключкой. Проверено на пресете оператора — часы встали на
место шаблонного текста.

Если этого поля нет в интерфейсе, приложение собрано до 7.0.7: правки
7.0.1–7.0.8 не попадают в уже установленную сборку без пересборки, а
media-service нужно перезапустить.
