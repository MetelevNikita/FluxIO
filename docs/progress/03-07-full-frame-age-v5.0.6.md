# 03.07 — полноэкранный AGE canvas v5.0.6

Дата завершения: 2026-08-07.

## Результат

- `0+.png`, `6+.png`, `12+.png`, `16+.png`, `18+.png` принимаются как
  полноэкранные RGBA-композиции 1920×1080 или 3840×2160.
- Позиция возрастной плашки задаётся непосредственно внутри прозрачного холста.
- FFmpeg использует `scale=OUTPUT_WIDTH:OUTPUT_HEIGHT` и `overlay=x=0:y=0`.
- Один UHD AGE asset можно использовать для HD output: он масштабируется вместе
  с координатами и размерами плашки.
- AGE folder matcher принимает только PNG/WebP. JPEG/JPG остаются допустимыми
  для channel logo, но не для полноэкранного AGE.
- Если подходящей графики нет, сохраняется существующий текстовый fallback.

## Проверка

- unit test проверяет full-frame scale и overlay `0:0`;
- `npm run typecheck`;
- `npm test`;
- `npm run build`.
