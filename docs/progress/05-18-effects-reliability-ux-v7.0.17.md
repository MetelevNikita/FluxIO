# Этап 05-18 — надёжность и UX Effects — v7.0.17

## Цель

Устранить молчаливые отказы при работе с `.json`, исправить отображение
композиций нестандартного размера и сделать создание эфирных плашек понятным
для инженера без ручной диагностики файлов и границ расписания.

## Что изменено

- Пакетный импорт эффектов возвращает исправные элементы и отдельный список
  ошибок: один повреждённый JSON больше не отменяет импорт всей папки.
- Ошибки импорта, загрузки системных шрифтов и чтения файла задания показаны в
  самом экране Effects; длительные операции имеют явное состояние занятости.
- Черновик инспектора применяется напрямую. Debounce библиотеки больше не может
  назначить предыдущую версию настроек или Lottie-свойств.
- JSON задания перечитывается после восстановления рабочей сессии. Для старых
  сессий путь мигрируется из `taskFilePath` в общую `dataMapping`.
- Сопоставление Dynamic Title и Next Program нормализует путь, расширение и
  регистр имени ролика. Неоднозначные записи не выбираются молча.
- План эффекта строится по единой очереди Current + Future, поэтому Next Program
  и две половины Stinger работают на автоматической границе расписаний.
- Координаты живого `drawtext` для узких Lottie-композиций приводятся в эфирный
  кадр тем же `contain`, которым FFmpeg масштабирует alpha-MOV. Проверено на
  `title_JSON_3.json` с холстом 1080 × 200.
- Сдвиг плашки и текста разрешён за пределы кадра без скрытого clamp к 0…100%.
- При выборе стингера FFprobe заполняет длительность, FPS, pixel format, наличие
  alpha и audio. Несовместимый alpha-режим и отсутствующая аудиодорожка видны до
  применения.
- JSON Parser предлагает объединённый набор полей всех записей, поддерживает
  закрытие по Escape/фону и удерживает клавиатурный фокус внутри диалога.
- Панель применения перенесена после настроек и закреплена у нижнего края;
  предпросмотр сворачивается, список шрифтов фильтруется поиском, числовые поля
  сохраняют незавершённый ввод и ограничивают значение при потере фокуса.
- FluxIO Title Studio экспортирует `matchSourceKey` и готовые `dataBindings`,
  корректно описывает семейство/начертание шрифта и показывает Lottie внутри
  выбранного кадра FHD, UHD, SD PAL или композиции AE.
