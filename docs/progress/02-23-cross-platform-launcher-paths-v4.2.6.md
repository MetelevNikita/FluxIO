# 02.23 — Кроссплатформенные пути launcher в v4.2.6

## Проблема

Тест `desktop launcher resolves relocatable production entries` выполняется на
Windows, но проверяет также Linux deployment path `/srv/FluxIO Project`.
Системный `path.join()` в Windows заменял `/` на `\`, поэтому Linux-путь
превращался в `\srv\FluxIO Project\...` и останавливал `setup.mjs` на этапе
тестирования.

## Исправление

`launcherPaths()` теперь выбирает реализацию пути по формату корня:

- абсолютный путь `/...` обрабатывается через `path.posix`;
- путь с буквой диска `C:\...` и UNC-путь обрабатываются через `path.win32`;
- относительный путь использует реализацию текущей операционной системы.

Это сохраняет нативные Windows paths при реальном запуске FluxIO и одновременно
позволяет надёжно генерировать и тестировать relocatable entries других ОС.

## Проверка

Регрессионный тест проверяет все формы в одном запуске:

- `/srv/FluxIO Project/apps/media-server/dist/index.js`;
- локальные диски `C:`, `D:` и `R:` как примеры любой буквы диска;
- сетевой UNC-корень `\\media-server\FluxIO Project`.

Версия всех компонентов: `v4.2.6`.
