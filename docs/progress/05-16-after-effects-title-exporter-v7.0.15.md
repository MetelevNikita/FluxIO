# Этап 05-16 — Flux Title Exporter для After Effects — v7.0.15

## Результат

Подготовлена первая рабочая версия панели After Effects, которая компилирует
выбранную композицию в безопасный Lottie-поднабор для FluxIO.
Дизайнер выбирает динамические Text Layer и связывает Shape Layer с текстом,
не переименовывая слои исходного `.aep`.

После этапа прототип вынесен из репозитория эфирного приложения в самостоятельный
companion-проект `FluxIO-Title-Studio`, расположенный рядом с `FluxIO`.

## Панель After Effects

Актуальный JSX backend отдельного проекта:

```text
../FluxIO-Title-Studio/extension/jsx/host.jsx
```

Реализовано:

- выбор композиции открытого проекта AE;
- список динамических Text Layer;
- связь Shape Layer → Text Layer для отзывчивой плашки;
- проверка длительности, размеров, дубликатов имён и статичного Rectangle;
- предупреждения для effects, masks, 3D, track matte и неподдерживаемых shapes;
- экспорт Text, Shape, Solid, Null, precomp и статичных image assets;
- transform-анимация, Source Text keyframes, Fill, Stroke, Trim Paths и markers;
- отчёт `.flux-report.txt` рядом с экспортированным JSON.

## Интеграция FluxIO

Экспортёр записывает `meta.flux.schemaVersion = 1`. FluxIO использует метаданные
как необязательное расширение Lottie:

- обычный Bodymovin JSON по-прежнему показывает все Text Layer;
- JSON из Flux Title Exporter показывает только выбранные в AE динамические поля;
- постоянные подписи остаются в картинке, но не попадают в JSON Parser;
- предупреждения экспортёра показываются в инспекторе Lottie;
- `fit:<Text Layer>` продолжает быть единственным эфирным правилом отзывчивого фона.

## Проверка отзывчивой подложки

Добавлен автоматический тест полного пути `override → font metrics → fit`:

```text
исходный текст: AB       ширина плашки: 300 px
новый текст:    ABAB     ширина плашки: 390 px
высота:                  100 px → 100 px
позиция центра:             0 px → 45 px
```

Разница ширины текста равна 90 px. Плашка увеличивается ровно на 90 px,
а смещение центра на 45 px оставляет левый край неподвижным для left alignment.

Также выполнен реальный DotLottie → FFmpeg QTRLE render эталонного проекта:
короткий `Title` получил короткую красную подложку, строка
`A longer dynamic title` — длинную подложку с теми же высотой, скруглением и
левым внутренним отступом.

## Ограничения MVP

- панель должна быть проверена внутри реального After Effects: на машине
  разработки AE не установлен;
- expressions лишь фиксируются предупреждением;
- gradients, repeaters, masks, track matte, cameras/lights, видео-footage и
  сторонние plug-ins не входят в безопасный поднабор;
- для сложного оформления используется гибрид: сложный декор запекается в alpha
  MOV, а текст и отзывчивый фон остаются параметрическими в FluxIO.
