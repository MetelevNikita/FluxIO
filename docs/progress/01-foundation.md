# Этап 1: фундамент проекта

- Статус: завершён
- Дата: 2026-08-03

## Что реализовано

- Создан npm workspaces монорепозиторий.
- Создан общий TypeScript-конфиг со строгими проверками.
- Добавлен пакет `@gruber/contracts` с runtime-схемой Zod.
- Добавлен Node.js/Fastify media service.
- Реализован `GET /api/health`.
- Добавлен React/Vite интерфейс, который проверяет соединение с media service.
- Добавлена безопасная Electron-оболочка с `contextIsolation`, отключённым `nodeIntegration` и sandbox renderer-процесса.
- Добавлен контрактный тест health endpoint.
- Записаны требования, архитектура, ADR и план разработки.

## Почему этот этап был первым

FFmpeg, медиатека и плейлист будут использоваться одновременно API, web-интерфейсом и Electron. Общие контракты и независимый media service предотвращают ситуацию, когда бизнес-логика оказывается привязана к одному окну или UI-фреймворку.

Health endpoint является первым вертикальным срезом: запрос проходит от React через HTTP до Node.js и проверяется общей схемой, используемой обеими сторонами.

## Текущие ограничения

- Media service пока не проверяет наличие FFmpeg.
- UI содержит только рабочие области и индикатор соединения.
- Electron запускает web-интерфейс, но установочный пакет ещё не формируется.
- Удалённый доступ и аутентификация намеренно не включены.
- Автоматическое одновременное открытие трёх dev-процессов будет добавлено после появления устойчивого server API.

## Следующий этап

Этап 2 добавит слой `ffmpeg-engine` и endpoint системных возможностей. Media service будет запускать `ffmpeg` и `ffprobe` безопасно через массив аргументов, определять версии, protocols, muxers, encoders и аппаратное ускорение. UI получит диагностическую страницу с реальными возможностями сервера.
