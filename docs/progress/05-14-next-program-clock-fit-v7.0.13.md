# Этап 05-14 — динамические Next program и Clock / countdown — v7.0.13

## Что изменено

- `Next program` больше не запекает название следующего материала внутрь
  Lottie. Выбранный Text Layer очищается, а реальное название рисует FFmpeg.
- Положение, кегль, цвет и выключка живой надписи снимаются с выбранного
  текстового слоя пресета так же, как у `Dynamic title`.
- Для Shape Layer `fit:<имя поля названия>` передаётся `fitSample` конкретного
  следующего фильма. Подложка сохраняет отступы шаблона и получает отдельный
  кэш-рендер только для уникальной ширины.
- `Clock / countdown` уже использовал живой `drawtext` и образец самого
  широкого значения формата. В инспектор добавлена явная подсказка об имени
  `fit:<поле>`, а поведение описано в runbook.
- В инспекторе `Next program` оформление живой надписи доступно и при выбранном
  Lottie-пресете; предпросмотр показывает текст отдельно от декора.

## Готовые пресеты

В `examples/dynamic-title-ae-reference/` добавлены:

- `FluxIO_Next_Program_Test.json` — поля `next_title`, `next_subtitle` и
  адаптивная подложка `fit:next_title`;
- `FluxIO_Clock_Countdown_Test.json` — поля `clock`, `clock_caption` и
  адаптивная подложка `fit:clock`.

Оба файла имеют прозрачный фон, анимацию появления, встроенный подмноженный
Noto Sans с кириллицей и проходят штатный Lottie-анализатор FluxIO. Проверен
повторный рендер с длинным названием и форматом `00:00:00`: предупреждений
подгонки подложки нет.
