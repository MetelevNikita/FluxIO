# 05.13 — Animated logo formats v7.0.12

Дата завершения: 2026-08-20.

Исправлен отказ Start при использовании анимированного логотипа: FFmpeg-цепочка
уже умела читать MOV и GIF, но preflight media-service пропускал только
PNG/WebP/JPEG.

Реализовано:

- preflight принимает PNG, WebP, JPEG, GIF, MOV, MP4, M4V, WebM, MKV, AVI и MXF;
- GIF повторяется через собственный demuxer, остальные видео — через `stream_loop`;
- однократная анимация после завершения остаётся на последнем кадре и не обрезает эфир;
- Lottie JSON при выборе логотипа автоматически рендерится в alpha-MOV;
- Lottie из `insertLogoTitle` импортируемого расписания проходит ту же подготовку;
- папка логотипов теперь ищет изображения, видео, GIF и Lottie;
- Loop определяется по фактическому подготовленному файлу, в том числе при выборе папки;
- ошибка неподдерживаемого формата перечисляет актуальный набор.

Проверка:

- общий TypeScript typecheck;
- полный набор unit-тестов;
- production build;
- тест распознавания MOV/GIF и запрета сырого JSON на входе FFmpeg.
